## 2. Script Format (HER template — always follow this)

One ad batch = **multiple Headings (or Heading + Subheading) + ONE shared Body + ONE shared CTA**.
Videos are assembled per combination, e.g. "Video 1 = Heading 1 + Body 1.1 + 1.3 + 1.4".
Naming: `H1/H2/H3…` = heading variants; campaign names carry them (e.g. `[H1H2H3] BJ: OPEN MANUAL`, `200225 KLCC: OPEN H4 & H8`, `BJ Jen VO H1-H4`).
Campaign name convention: `DDMMYY AREA: TYPE (AUDIENCE)` e.g. `090326 BJ: WEBINAR (ENG) - (MSIA/SG)`.

Structure of a full script:
1. **Heading** (hook, 3–10s, unique per version)
2. **Linkage** (bridge to the webinar problem, often shared within a topic cluster)
3. **Body** (webinar pitch, shared across the whole batch)
4. **CTA** (shared; "click below" + bonus reveal "which project we bought & why")

## 3. Hook Playbook (what she rotates)

- **Project-name listing**: "Park Green, Queenswoodz, Kingswoodz, OAKA, Vividz… more than 10 projects in Bukit Jalil. Which one is most suitable for you?" (targets people mid-research)
- **Fear / loss**: "One Wrong Decision = pay up to RM3000 every month", "Don't invest in any Airbnb property before you watch this"
- **Negative command / pattern interrupt**: "You're out, if you still invest in Airbnb properties", "Stop looking at Bukit Jalil projects if you haven't watched this"
- **Agent-conspiracy / secrets**: "secrets that property agents don't want you to know", "Are they more focused on their commission than your profit?"
- **News-jacking**: earthquake tremors, Putra Heights gas explosion, SST increase, Iran war, condo bans Airbnb, 2008 crash
- **Myth-busting with numbers**: "They tell you AirBnb can get 10% ROI… why are 93% of investors still losing money?"
- **Question hook**: "Thinking to invest in KLCC but not sure which project has the best ROI?"
- **Status/exclusion (Chinese luxury line)**: "如果你的身家没到千万级别，请立刻划走"
- **Story**: "my friend bought an AirBnb project in KLCC and he is losing RM2700 every month"

## 7. Production Style (video)

- Shoot horizontal, edit both horizontal + vertical; VO versions vertical
- B-roll: drone shots of area (BJ stadium/roads, KLCC skyline), VR/map views with project names popping one-by-one (with ding sounds), webinar-presenter crops "thrown-photo" effect, news footage for news-jack hooks
- Effects: CapCut, ❌ stamps with bi-bi sound, green highlight, censored project names (curiosity device), suspense BGM for fear hooks
- Subtitles: not too colorful; emphasis words bolded
- Scripted blocking: "(Turn left)", "(sit down first then start talking)", camera-man as a character in Malay skits

## 9. Learning Rules (how to use other people's ads)

- Jennifer feeds in OTHER people's ads for study — those can be ANY type (product, course, service, e-com, not necessarily webinar or property).
- From those ads: extract only the **transferable techniques** — hook patterns, pacing, editing tricks, copy structures, CTA psychology.
- But HER ads are always **webinar lead-gen** (Bukit Jalil Webinar / KLCC Webinar → lead form → free live group webinar). When generating scripts for her, ALWAYS adapt any borrowed technique into that funnel — never copy another ad's offer/funnel type.
