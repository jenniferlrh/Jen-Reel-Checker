# Jen Reel Checker

🎬 A modern web application for analyzing Instagram reels. Get AI-powered insights into what makes content go viral.

## Features

- 📊 Analyze Instagram Reels in real-time
- 🎯 Hook strength scoring and engagement metrics
- 📝 Automatic transcription (coming soon)
- 💾 Save analyses as markdown
- 🎨 Beautiful modern UI with gradients and animations

## Tech Stack

- React 18
- Vite
- CSS3
- JavaScript ES6+

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.

## Build

```bash
npm run build
```
